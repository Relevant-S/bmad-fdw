- (decision) Fidelity outranks portability, stated explicitly, because leaving the two unranked is what produced the failure. Phone review is served by running the real app beside the prototype, not by degrading the artifact to a double-clickable file.
- (pattern) Grounding pattern, deliberately stack-agnostic — every rule keys off what the project turns out to have: (a) discovery ladder that cannot end in a guess — config, auto-detect, widen to parent and siblings, ask the BA; inventory returns verdict:not_found and never claims greenfield, which is now a state the BA confirms by name; (b) fidelity kit instead of a name list — stack with per-app run commands, components, token source files, real pages ranked by archetype; (c) clone-then-change: take the nearest real page of the same archetype and change only what the feature changes; (d) design/grounding.json as a machine-checked record of where each screen came from; (e) boundary held by set difference over declared vs present screens, plus chrome.origin restricted to borrowed-with-a-source or none.
